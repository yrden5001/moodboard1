Sobre este proyecto

Aprender creando experiencias digitales.

Este proyecto fue desarrollado durante el primer ciclo de Arquitectura de Entorno Web. A través de MOODBOARD, aplicamos conocimientos de HTML, CSS y JavaScript para construir una experiencia digital relacionada con la moda, el diseño y la navegación web.

Cada integrante participó desde sus habilidades, contribuyendo al diseño, la estructura, la programación, el contenido y la integración del sitio.
